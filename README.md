# TakeNotes

**The notebook that knows what you forget.** An iPad study notebook: one notebook per subject, handwritten with Apple Pencil. What you underline or circle becomes a question, and questions come back right before you'd forget them.

**Open the app:** https://blik.design/TakeNotes/
**Clickable design prototype (with demo data):** https://blik.design/TakeNotes/demo/

## Install on iPad
1. Open the link in **Safari**.
2. Tap **Share → Add to Home Screen**.
3. Open TakeNotes from the Home Screen — it runs full screen and works offline.

## What works in this version
- Onboarding, notebooks per subject (lines / grid / dots / blank paper, switch any time)
- Writing with Apple Pencil: pressure, highlighter, eraser (also the Pencil eraser), undo/redo, photos
- Fingers scroll, two-finger tap undoes (finger drawing can be turned on in Settings)
- Marks without AI: **underline** a line or **circle** a word/formula → it becomes a question; or drag a box with the **Q** tool
- Test myself on a page, quizzes per notebook, daily due questions with spaced repetition
- Weekly timetable — the right notebook opens during class; exam countdowns
- Works on all iPad sizes, portrait and landscape

## Good to know
- Everything is stored **only on this iPad** (in the browser storage of the installed app). Export a backup in Settings now and then.
- This is the web version. Notifications, lecture recording and sync come with the native app.
